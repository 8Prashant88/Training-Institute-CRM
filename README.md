# Training Institute CRM

A responsive training institute CRM built with Next.js, TypeScript, Tailwind CSS, Zod, and Server Actions.

## Live Demo

[Open the deployed application](https://training-institute-crm-t6ul.vercel.app)

## Main Features

- Public course inquiry form
- Runtime validation with Zod
- International phone-number support
- Lead creation and editing
- Lead filtering and selection
- Responsive dashboard
- Courses and batches overview
- Loading, error, empty, and not-found states
